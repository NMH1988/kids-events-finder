### T5.3 Trip plan box from the tool results (M) · status: todo · issue #22
**Serves:** Capstone (`docs/CAPSTONE_CHECKLIST.md`): interactive prototype, user interface and interaction quality, function calling (tool results shown by the app); Legal (`docs/LEGAL_COMPLIANCE.md`): 4.3 (grounding: facts from tools, shown by code), 7.3 (never invent times; check bahn.de), 6.3 (source credits).
**Depends on:** none
**Acceptance criteria** (drafted by Claude, approved by the owner on 2026-11-24)
- [ ] When a turn used `find_train_connection`, the app shows a box under the answer with every journey of every train search in that turn (so both the way there and the way back): date, from, to, departure, arrival, duration, transfers, rides, and the live-data, delay and cancelled notes where the result has them - verified by unit tests of a new extractor next to `calculations()` in `src/agent/runner.py` and an `AppTest`.
- [ ] When the turn used `get_weather_forecast`, the box shows each day's summary, lowest and highest temperature and rain chance from the result - verified by the same tests.
- [ ] Service text (station, line and town names) is shown as plain text, never as Markdown or HTML: a ride named `[x](https://evil.example)` or `<img src=x>` appears literally - verified by a test.
- [ ] The box says that it is right where the AI's text differs, ends with "Train times and fares can change: check bahn.de or the DB Navigator app before you travel.", and the existing source credits stay - verified by an `AppTest`.
- [ ] A turn without these tools shows no box, and a tool result with an `error` field is left out - verified by unit tests.
- [ ] The system prompt is unchanged - verified by the PR's diff (no change under `src/prompts/`).
**Notes:** files: `src/agent/runner.py` (`TurnResult` gets the plan data), `views/chat.py` (render next to `_render_calculations`), `src/config.py` (the set of plan tools). No new data flow: the results are already in the conversation. Shortening the model's own trip layout because the box shows the times would be a system prompt change and needs the owner's approval (T1.5, O2); not part of this ticket.
