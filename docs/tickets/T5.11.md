**Acceptance criteria** (drafted by Claude, approved by the owner on 2026-11-25, option A without liked places; AC1 reworded by the owner's decision on 2026-11-25, see Notes)
- [x] A sidebar switch "Remember our preferences on this computer" is off by default; while it is off, nothing is saved to long-term memory and nothing from it is sent to the model - verified by an `AppTest` in `tests/test_app.py` and unit tests in `tests/test_memory.py`.
- [x] With the switch on, the agent can save a preference only through the internal tool `remember_preference`, whose arguments are fixed choices (a place category, indoor or outdoor; likes or avoids); free text, place names, age groups, the budget and the family size cannot be stored - verified by schema tests and a test that the store holds only allowed keys and values.
- [x] In a new conversation (a new `thread_id`) the saved preferences reach the model as one line of the system prompt built by code - verified by a graph test with a fake model across two threads in `tests/test_memory.py`.
- [x] Each preference saved in a turn is shown under the answer ("Remembered for next time: likes museums") and listed in the sidebar; "Forget everything" deletes them at once, also from the file - verified by `AppTest`s and a unit test.
- [x] A preference is deleted 30 days after it was last saved (`LONG_TERM_MEMORY_RETENTION_DAYS`) by the background cleaner and when the memory is loaded - verified by a unit test with a fixed clock.
- [x] Short-term memory: the messages sent to the model are trimmed to `MAX_HISTORY_TOKENS`, never splitting a tool call from its result and never dropping the latest question; the whole thread stays in the checkpointer for the grounding check - verified by unit tests of the trim function and a graph test.
- [x] The About page, `docs/LEGAL_COMPLIANCE.md` (processing register, 2.7, "Before a public deployment": memory off or moved to the parent's device) and `docs/CAPSTONE_CHECKLIST.md` (memory row split into short-term and long-term, an "OpenAI API" row) are updated - verified by the legal-reviewer's PASS and `tests/test_docs_layout.py`.
- [x] The owner approved the system prompt change (rule from T1.5, O2) - verified by the owner's approval recorded in the PR (2026-11-25).
