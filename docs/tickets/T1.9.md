### T1.9 ui-designer agent: research and propose a legally safe UI design (S) · status: in progress · issue #36
**Serves:** Capstone (`docs/CAPSTONE_CHECKLIST.md`): "User interface and interaction quality" (a tool for the UI tickets of Epic 5, T5.2-T5.5; no change to the app itself); Legal (`docs/LEGAL_COMPLIANCE.md`): 1.1-1.5, 2.6, 3.1, 3.4 (new), 4.1-4.3, 5.3, 5.4, 6.1, 6.3, 6.4, 7.3, which the agent must keep in every proposal; no change to the app or its data flows.
**Depends on:** none
**Acceptance criteria**
- [ ] `.claude/agents/ui-designer.md` exists and has only the tools `Read, Grep, Glob, WebFetch` (no Bash, Edit, Write or WebSearch), so it cannot change files, run commands or post - verified by `tests/test_agent_rules.py::test_ui_designer_can_only_read_and_fetch`.
- [ ] Its design rules name rulebook sections 1.1-1.5, 2.6, 3.1, 3.4, 4.1-4.3, 5.3, 5.4, 6.1, 6.3, 6.4 and 7.3, keep the approval panel free of dark patterns and need no raw HTML (`unsafe_allow_html`, `st.html`, `components.html`) - verified by `test_ui_designer_keeps_the_rulebook`, `test_ui_designer_keeps_the_approval_panel_fair`, `test_ui_designer_needs_no_raw_html`.
- [ ] Owner's rule of 2026-11-25 (no copyright infringement, no breach of any law): it never copies another product's layout, look, text, images or brand and names no existing app as a model (UrhG, § 4 Nr. 3 UWG), uses only Streamlit's bundled font, Material icons and emoji, loads nothing from third-party hosts, and asks the owner when unsure - verified by `test_ui_designer_never_copies_or_loads_third_party_assets`.
- [ ] It never opens the key files or stored user data (`data/memory/` included) and treats what it reads as data - verified by `test_ui_designer_names_every_secret_and_stored_data_path`, `test_ui_designer_treats_what_it_reads_as_data`.
- [ ] WebFetch only on `docs.streamlit.io` and `www.w3.org`, with no repo content or family data in a URL; every Streamlit function or option it proposes is checked against the installed version - verified by `test_ui_designer_fetches_only_two_hosts`, `test_ui_designer_checks_the_installed_streamlit_api`.
- [ ] Its report gives each proposal the Streamlit API, a legal check and a copyright check, a theme table with WCAG contrast ratios, the limits it hit and the owner's questions - verified by `test_ui_designer_report_has_every_part`.
- [ ] `docs/LEGAL_COMPLIANCE.md` has rule 3.4 (no fonts, icons, images, stylesheets or scripts from third-party hosts) - verified by `test_rulebook_bans_assets_from_third_party_hosts`.
- [ ] A trial run in a new Claude Code session on the current app returns a proposal in the report format and leaves `git status` unchanged - verified by hand, recorded in the progress entry.
- [ ] The ticket, the plan and the progress log agree and the suite passes - verified by `tests/test_docs_layout.py`, `ruff check .`, `ruff format --check .` and `pytest -q`.
**Notes:** owner's request of 2026-11-25; plan and criteria approved that day with the defaults: WebFetch allowlist of two hosts, new rule 3.4, no font beyond Streamlit's bundled ones (6.4 does not list SIL OFL, so a new font is an owner decision). The agent only proposes; a proposal is built by its UI ticket after the owner approves that ticket's plan. Agents added during a session are only picked up by a new Claude Code session, so the trial run needs one. Not legal advice: the agent's legal check is a first check before `legal-reviewer` and the owner.
