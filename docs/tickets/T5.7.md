**Acceptance criteria** (drafted by Claude, to be approved by the owner)
- [ ] The `search_knowledge_base` caption says the search text goes to the AI model service to find matches and that nothing goes to map, event or weather services, instead of "Nothing leaves the app" - verified by an `AppTest` that finds the new caption.
- [ ] A lone surrogate in a model's tool-call name or arguments is replaced before the message is stored, so the next model request of that conversation still encodes as UTF-8 and the turn completes - verified by a graph test with a scripted model in `tests/test_agent.py`.

- [ ] The approval panel's widget keys use a hash of the call id, so a call id with any character never breaks the panel, and the keys still change with the pause - verified by an `AppTest` with such a call id and `test_approval_widgets_are_keyed_by_the_pause`, adapted.
- [ ] The system prompt is unchanged - verified by the PR's diff (no change under `src/prompts/`).
