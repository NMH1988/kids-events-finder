### T5.15 Light and dark colour theme with tested contrast (S) · status: todo · issue #42
**Serves:** Capstone (`docs/CAPSTONE_CHECKLIST.md`): user interface and interaction quality; Legal (`docs/LEGAL_COMPLIANCE.md`): 3.1 and 3.4 (no outside font or base theme, usage stats off), 6.4 (only the fonts inside Streamlit), 4.1 (the AI label stays readable), 1.1 (a calm, adult look).
**Depends on:** T5.12, T5.2 (no primary button left)
**Acceptance criteria** (drafted by Claude, approved by the owner on 2026-11-26)
- [ ] `.streamlit/config.toml` sets `[theme.light]` and `[theme.dark]` with the values of `docs/design/ui-design-spec.md` (primary, background, secondary background, text, link and border colours, and the six palette colours with their `<colour>TextColor` and background colours; red keeps Streamlit's default), plus `linkUnderline = true` and `showWidgetBorder = true`; the old top-level `[theme] primaryColor = "#f97316"` is removed - verified by a test that reads the file.
- [ ] A test computes the WCAG 2.2 contrast of every text colour on the page and secondary backgrounds and of every `<colour>TextColor` on its own background colour, for both themes, and fails under 4.5:1; borders and the primary colour as an interface part fail under 3:1 - verified by that test.
- [ ] No `type="primary"` button is left in `views/` or `app.py` (white text on the dark accent is only 2.80:1) - verified by a test that searches the code; if T5.2 (PR #31) has not removed the Approve button's `type="primary"` yet, this ticket waits for it.
- [ ] The file sets no font with a URL, no `[[theme.fontFaces]]`, no `base`, and keeps `gatherUsageStats = false` - verified by a test.
- [ ] Every option set is a real option of the installed Streamlit (no typo is ignored silently) - verified by a test that checks each key against `streamlit.config` option names.
- [ ] In the running app, the owner checks the light and the dark theme once (how Streamlit picks between them, and the caption colour) and the result is recorded in the progress entry - verified by hand, with synthetic questions only.
