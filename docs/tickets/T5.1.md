[Implementation plan](../IMPLEMENTATION_PLAN.md) · Epic 5: Capstone demo: UI and agent

### T5.1 Live progress while the agent works (M) · status: todo · issue #20
**Serves:** Capstone (`docs/CAPSTONE_CHECKLIST.md`): interactive prototype, user interface and interaction quality, evaluation (responsiveness); Legal (`docs/LEGAL_COMPLIANCE.md`): 4.3 (no answer text before the grounding check), 2.10 (quiet logs).
**Depends on:** none
**Acceptance criteria** (drafted by Claude, approved by the owner on 2026-11-24)
- [ ] `start_turn` and `resume_turn` take an optional progress callback and report each step while it happens, in order: the model planning, each tool by its readable label, the grounding check - verified by a graph test with a fake model and fake tools in `tests/test_agent.py`.
- [ ] The callback receives only step labels from a fixed list in the app (a tool the list does not know is reported as "a tool"), never model text, tool arguments or tool results - verified by a test whose fake answer, arguments and tool result carry a marker string that no progress event contains.
- [ ] The chat shows the steps in a status box during the turn and closes it when the answer or the approval panel appears - verified by an `AppTest` in `tests/test_app.py` with a fake graph (or a unit test of the view's event-to-label function where `AppTest` cannot read the box).
- [ ] `TurnResult` and the approve, edit, reject and auto-approve flows are unchanged - verified by the existing tests in `tests/test_agent.py` and `tests/test_app.py`, passing without changes.
- [ ] Progress events are not logged - verified by a `caplog` test.
**Notes:** files: `src/agent/runner.py` (`graph.stream` with `stream_mode="updates"` instead of `graph.invoke`), `views/chat.py` (`st.status` in place of the spinner), the step labels in `src/config.py` or next to `TOOL_EXPLANATIONS`. No token streaming: the answer must pass the grounding check before the parent sees any of it (4.3). Makes the 30-second SMART target easier to bear in the demo and the user tests (O5); it does not make the model faster.
