### T5.8 Wrong-country measure by website, and a re-run (S) · status: todo · issue #32
**Serves:** Capstone (`docs/CAPSTONE_CHECKLIST.md`): evaluation (accuracy: the wrong-country measure and its 0% target); Legal (`docs/LEGAL_COMPLIANCE.md`): 4.3 (grounding: removed links), 8 (synthetic questions only), registers (the re-run's tools receive only town names, dates and categories); `docs/THIRD_PARTY_TERMS.md` (checklist before the re-run).
**Depends on:** T1.8
**Acceptance criteria** (drafted by Claude, to be approved by the owner)
- [ ] `scripts/evaluate_agent.py` flags an answer as wrong-country when a link in the answer, or a link the grounding report removed, points to the website of a curated place from another country, matched by host and path prefix (so two places that share a host, such as the LEGOLAND Discovery Centres in Berlin and Manchester, are told apart); a place name counts only when it is not generic (it does not appear inside the name of a curated place from the question's own country, and it is not on a short list of generic names such as "Natural History Museum" and "Science Museum") - verified by unit tests with made-up answers: a Los Angeles answer naming "Natural History Museum of Los Angeles County", a Berlin answer saying "Berlin's natural history museum" and a Manchester answer linking its own LEGOLAND Discovery Centre are not flagged; a Berlin answer linking the London Natural History Museum's website, or whose removed links hold it, is flagged.
- [ ] The grounded rate is computed as before; a removed link counts as wrong-country only when it points to another country's curated website - verified by unit tests: a removed link to an unknown site lowers the grounded rate and leaves wrong-country at 0.
- [ ] Removed links are compared by their host and path in code only: never fetched, never printed or stored; the script still prints and stores only ids and metrics, never answer text - verified by a unit test on the printed line and the CSV row.
- [ ] One `--judge` re-run with `openai/gpt-5-mini` after the owner's go-ahead (the checklist in `docs/THIRD_PARTY_TERMS.md`, ordinary questions only) and its row in `docs/EVALUATION.md` with a sentence on whether the 0% target is met - verified by the printed summary, quoted in the progress entry.
**Notes:** follow-up from T1.8: the 2026-11-24 runs flagged 7 answers per model (0.206), probably in part from generic London museum names and a plain substring match; the cause of each flag is not known (`docs/EVALUATION.md`). The re-run is a paid call on the school's OpenRouter account (34 agent answers plus their helper and judge calls); the owner may decide to skip it, or to share one re-run with T5.9 if T5.8 is done first. No prompt, question or app code change. Runs since T5.11 offer the agent the `remember_preference` tool and a memory section in the system prompt, which the 2026-11-24 baseline did not have, so its figures are not directly comparable; the re-run keeps long-term memory off (the script's default), so no remembered preference reaches OpenRouter and the memory store is neither read nor written.
